Renpack

The binary form of a compressed tabular data set collection. It's a JSON envelope (without the rows or dictionary), followed by the dictionary and each column, packed at the narrowest width their values fit. It's recognised by its first four bytes, RENP, and Ren's Accept header (application/x-ren-tabular-v1) tells a server it can send one. It's read on a worker, so a big file doesn't hold up the page. (This file was written by the .NET package's RenPackWriter, from the collection example.)
