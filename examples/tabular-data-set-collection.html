Tabular data set collection

Ren's own JSON, which the other formats are converted into, and which a report server returns. It can carry several tabs, the columns' aggregation and formats, and a compression dictionary that the compressed columns index into. Any JSON that isn't one of the other formats is read as this.

Data: sales.collection.json

{
    "DataSourceUri": "...",
    "TabularDataSets": [{
        "Title": "Sales",
        "TabularDatas": [{
            "Title": "Sales",
            "IsColumnCompressed": [false, true, true, true, false, false],
            "ColumnModels": [{ "Heading": "Count", "Visible": false, ... }, ...],
            "RowModels": [{ "CV": [1, 0, 23, 17, 4, 14] }, ...]
        }]
    }],
    "CompressionDictionary": ["2026-07-01", ...]
}
