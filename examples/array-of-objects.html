Array of objects

One object per row, with each key being a column. Every object has to have the same keys. Ren works out the column types from the values, but if you want to give hints, you can send { "columns": [hints], "rows": [objects] } instead. It's recognised by the body starting with [.

Data: sales.array-of-objects.json

[
    { "Date": "2026-07-01", "Product": "Stapler", "Category": "Desk accessories", "Quantity": 4, "Revenue": 14 },
    ...
]
