Columns and rows

A columns array of column hints, and a rows array, with an array of values for each row (in column order). It's recognised by the body starting with {"columns":, so you only need data-format if rows comes first.

Data: sales.columns-and-rows.json

{
    "columns": [
        { "name": "Date", "type": "date" },
        { "name": "Product" },
        ...
        { "name": "Revenue", "format": "currency" }
    ],
    "rows": [
        ["2026-07-01", "Stapler", "Desk accessories", 4, 14.00],
        ...
    ]
}
