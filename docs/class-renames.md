# Class renames in 1.0.0

Ren 1.0.0 prefixes every class it defines or looks for, so they can't clash with a host page's own
classes.  This is the full list, for updating a page's markup, its CSS overrides of Ren's styles, and
any script that selects Ren's elements.

The rule is mechanical, so most names don't need looking up:
- Add `ren-` to the front: `data-grid__cell--group` becomes `ren-data-grid__cell--group`, and the
  date/value chart's `bar` becomes `ren-bar`.
- `js-*` hooks gain `ren-` after `js-`: `js-report-context` becomes `js-ren-report-context`.
  `js-ren-config` already had it, so it doesn't change.
- `qa-*` test hooks gain `ren-` after `qa-` too: `qa-calendar` becomes `qa-ren-calendar`.
- Classes built from a prefix are prefixed the same way: `series-<n>` becomes `ren-series-<n>`, and
  `grid-set-tab-*` and `tabbed-module-tab-id-*` become `ren-grid-set-tab-*` and
  `ren-tabbed-module-tab-id-*`.
- The data grid's per-cell classes are prefixed too: `r-<n>`, `c-<n>`, `cs-<n>` and `h` become
  `ren-r-<n>`, `ren-c-<n>`, `ren-cs-<n>` and `ren-h`.
- So are the generated GUID classes: `data-grid-<guid>`, `visualisation-<guid>` and
  `visualisation-static-<n>` become `ren-data-grid-<guid>`, `ren-visualisation-<guid>` and
  `ren-visualisation-static-<n>`, and the same goes for `popup-window-`, `filter-module-`,
  `function-editor-`, `toggle-switch-`, `date-value-` (now `ren-date-value-chart-`) and the
  dynamic stylesheets' `style-`.  A visualisation's target element, which had a bare `r-<guid>`,
  now has `ren-target-<guid>`.

Not renamed:
- Syntax-highlighting tokens inside the function editor and source views (`token`, `keyword`,
  `string`, `number`, `comment`, `rg-*` and the rest).  They're always inside a Ren block.
- `report-context-<guid>`, which the host page's server puts on each report context, and which
  saved settings name in their settings groups.
- `tick` and `domain` on chart axes.  They were d3's own names, and Ren's axes keep them.
- Element names (`<data-grid>`, `<grid-set>`, `<report-tabs>`, `<ren-*>`) and element ids.
- Classes on the host page's own elements that a page's settings point Ren at, such as a
  `targetSelector` of `.js-sales-menu`.
